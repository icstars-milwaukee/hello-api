## How to view the diagrams

Both files use [Mermaid](https://mermaid.js.org/), which GitHub renders natively — open `sdlc-swimlane.md` in the GitHub web UI and the diagrams appear as pictures rather than code. Each Mermaid diagram is followed by a plain-text swimlane table so the artifact is still readable in an editor, a PDF export, or a screen reader.
